# Meu Mecânico

Nova apresentação da Meu Mecânico, oficina em Ceilândia, DF.

## Páginas

- Página inicial: apresentação da oficina, guia de cuidados, história e contato.
- Quem somos: trajetória, equipe, propósito e valores.
- Reportagens: 43 registros do acervo, com busca e filtros.

Site estático, responsivo e independente de framework. Fotografias e marcas preservadas a partir do acervo oficial. Fonte Manrope com licença OFL nos assets.

Esta publicação é uma demonstração para avaliação. Não substitui o domínio atual da empresa.

## Executar localmente

Com Node.js 18 ou superior: `npm start`. Abra a URL indicada no terminal.

## Publicação

GitHub Pages usa a raiz da branch main. Caminhos relativos permitem servir o site em subpasta. A demo usa noindex,nofollow; revisar SEO e indexação antes da implantação no domínio definitivo.

Marca, fotografias e referências de imprensa pertencem aos seus respectivos titulares. O repositório não concede licença para reutilização desses elementos em outros projetos.
